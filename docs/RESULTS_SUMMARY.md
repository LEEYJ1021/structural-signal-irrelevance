# Results Summary

Consolidated statistics for Study 1 and Study 2's formal hypothesis
families (README §2), generated by `src/analysis/`,
`supplementary_robustness/`, and
`src/coldstart_v5/step_m_intervention_timing_simulation.py`. This document
is meant to be the single citable source for every reported number; the
root [`README.md`](../README.md)'s §4.6 ("H-S2.1 / H-S2.2 / RQ-S2.3
results at a glance") is a condensed pointer to this one, reproducing the
tables below verbatim -- cite this file, not the README, for the
underlying statistics. For the narrative of *why* each method looks the
way it does, see [`METHODOLOGY_NOTES.md`](METHODOLOGY_NOTES.md).

**Nomenclature:** the sections below were originally labeled "RQ1,"
"RQ2 / H2a / H2b," and "RQ3." As of the README's §2 theoretical-framing
revision, these correspond to **H-S2.1**, **H-S2.2a / H-S2.2b**, and
**RQ-S2.3** respectively (Study-2-prefixed, permanent IDs -- Study 1 has
its own, non-overlapping H-S1.x / RQ-S1.x family, summarized in the new
§1 below). Old and new labels are given together at each heading during
the transition.

Sample (Study 2): cold-start candidates = 250, trajectory-usable = 222,
after excluding two near-zero-spend template accounts (`config.yaml ->
sample_definition.known_test_account_ids`, see `METHODOLOGY_NOTES.md`
entry 7) = 207 ad groups / 29-30 customers, depending on the
window-completeness filter applied by each analysis (see each
hypothesis's exact n below).

## H-S1.1 (a/b/c) and H-S1.2 -- Study 1's confirmatory statistics

*(Added for coverage parity with Study 2, below -- this file is the
canonical statistics source for both studies, not Study 2 alone.)*

**H-S1.1a/b/c: full-mediation test (size -> spend -> outcome).**
Customer-level mediation model, `bid_amount` as the cost-independent
primary outcome (n=263 customers); CPC-based estimates retained for
comparison but treated as directionally informative only (mechanical
cost-sharing artifact -- see `supplementary_robustness/
01_alternative_outcome_mediation.md`).

| Path | CPC-based (secondary) | bid_amount-based (primary) |
|---|---|---|
| H-S1.1a (a-path): size -> total spend | +0.537 (p<.001) | +0.537 (p<.001) |
| H-S1.1b (b-path): spend -> outcome \| size | +1.277 (p<.001) | +0.150 (p=.032) |
| H-S1.1c (c'-path): size -> outcome \| spend (direct) | -0.253 (p=.062) | +0.037 (p=.634) |
| Indirect effect (a x b) | +0.253 | +0.081 |
| Bootstrap 95% CI, indirect | [0.121, 0.399] | [0.008, 0.159] |
| Permutation p, indirect | <.001 | <.001 |

**Verdict: H-S1.1c not rejected (null supported); H-S1.1a and H-S1.1b
both confirmed.** Full mediation -- the direct effect of size, net of
spend, is statistically indistinguishable from zero on the primary
(cost-independent) outcome, while both mediation legs are individually
significant. Backed by 8 independent robustness methods (specification
curve, placebo test, 2SLS, temporal replication, FDR correction, and the
mechanical-artifact isolation underlying this table); see README §3.4.

## H-S2.1 (formerly "RQ1") -- Does account maturity predict initial growth slope?

**H-S2.1**: account maturity (log all-time ad-group count, standardized) is
positively associated with a newly registered ad group's initial 30-day
growth slope.

**Primary method**: customer-level aggregate OLS (HC3 robust SE) --
n = customers, not ad groups, since maturity varies only at the customer
level (Step K established this is the effective sample size; MixedLM is
structurally non-identified against it, see `METHODOLOGY_NOTES.md` entry
4). **Final arbiter**: cluster (customer-label) permutation test.

| statistic | value |
|---|---|
| n (customers) | 29 |
| n (ad groups, informational) | 204 |
| OLS beta (raw scale) | 8.34 |
| OLS HC3 p-value | .576 |
| Bootstrap 95% CI (raw scale) | [-15.84, 43.08] |
| Cluster permutation p-value | .663 |
| Spearman rho | -.02 (p = .92) |
| Leave-one-out (largest customer excluded) permutation p-value | .702 (sign unchanged) |
| Winsorized (10%) OLS beta / p | 1.48 / .841 |
| Rank-rank OLS beta / p | -.02 / .924 |
| Standardized effect size (beta) | .085 |
| Pre-registered large-effect detection threshold | .50 |
| Observed effect as % of detection threshold | 16.9% |

**Verdict: H-S2.1 not supported.** Five independent checks (raw OLS,
bootstrap CI, cluster permutation, leave-one-out, Winsorized/rank-rank
OLS) agree; the small positive raw-scale coefficient is attributable to
a handful of high-leverage observations (it collapses under Winsorizing
and reverses sign under a rank transform). The standardized effect size
(.085) sits well below even the small-effect band evaluated in the Step
K power simulation, indicating this is a genuine null rather than an
under-powered detection -- enlarging the sample would be unlikely to
change the conclusion. A TOST equivalence test against this null is not
yet formally established (README §7.1) -- see the caveat in the combined
takeaway below.

## H-S2.2a / H-S2.2b (formerly "RQ2 / H2a / H2b") -- Do early operating signals predict later growth, and does maturity add value?

**H-S2.2a**: early-window features (coverage, spend level/slope, CTR/CVR/
ROAS) predict later-window growth. **H-S2.2b**: adding account maturity
improves on H-S2.2a.

**Method**: Ridge regression, repeated customer-grouped train/test
splits (Wilcoxon signed-rank test on the paired improvement) +
Leave-One-Customer-Out CV, decomposed into within- and
between-customer components (Step L / `METHODOLOGY_NOTES.md`, entry
5).

| early/later window (days) | n (ad groups) | H-S2.2a within-customer LOCO rho | H-S2.2b within-customer LOCO rho | within-customer improvement | repeated-split Wilcoxon p |
|---|---|---|---|---|---|
| 14 / 14 | 204 | 0.467 | 0.487 | +0.019 | .038 (H-S2.2b *worse* on repeated-split rho) |
| 30 / 30 | 184 | 0.275 | 0.257 | -0.018 | .119 |
| 30 / 60 | 179 | 0.060 | 0.061 | +0.001 | .019 (H-S2.2b *worse* on repeated-split rho) |

**Verdict: H-S2.2a supported at short horizons, decaying sharply beyond
them; H-S2.2b not supported at any horizon.** 14-day-ahead prediction shows
substantial within-customer signal (rho ~ 0.39-0.47 depending on
evaluation design); this decays to near zero by the 30/60-day horizon.
Adding account maturity never produces a within-customer improvement
exceeding +0.02 at any window pair, and the repeated-split design finds
the addition significantly *harmful* at two of three window pairs.
Pooled/between-customer improvements that appear positive (e.g. +0.388
between-customer at 30/60d) are attributable to H-S2.1-level signal
leaking into a pooled metric, not genuine ad-group-level gain (see
`METHODOLOGY_NOTES.md`, entry 5).

## RQ-S2.3 (formerly "RQ3") -- At what point should a low-growth ad group be flagged for intervention?

**Method**: precision/recall/lift of early-signal-based flagging against
realized low-growth outcomes at candidate decision cutoffs (7/14/21
days), evaluated on a fixed 44-day total horizon so cutoffs share an
identical ad-group population. This is the only *measured* RQ-S2.3
result; see below for why the accompanying expected-uplift simulation is
not reported as a policy conclusion. Per README §2.2's naming convention,
RQ-S2.3 is treated throughout as exploratory/design-science rather than
a single confirmatory point-null test; the design artifact it motivates
(**DA-S2.1**) is specified in full in
`supplementary_robustness/04_design_artifact_future_work.md`.

| decision cutoff (days) | out-of-fold predictive rho (95% bootstrap CI) | lift @ threshold=0.25 | lift @ threshold=0.40 |
|---|---|---|---|
| 7 | 0.304 [0.145, 0.445] | 0.83 | 1.27 |
| 14 | 0.265 [0.123, 0.404] | 1.33 | 1.23 |
| 21 | 0.334 [0.210, 0.459] | 1.42 | 1.36 |

(threshold = 0.10 excluded from reported results -- Step M6-1 found
12.6-13.1% of ad groups have `growth_target == 0`, which destabilizes
quantile cuts at this narrow a band.)

**Verdict: directional, not precise.** Flagging achieves 1.2-1.4x lift
over random across all tested cutoffs and reliable thresholds (see the
table above: the reported lifts span 0.83x-1.42x across cells, with the
reliable, non-degenerate range for both thresholds at both a lower and
upper cutoff sitting at roughly 1.2x-1.4x). The 95% bootstrap confidence
intervals on predictive rho overlap substantially across all three
cutoffs, so no single cutoff is statistically distinguishable as
"optimal" -- reported as "early judgment (within 3 weeks of
registration) is viable; a single precise optimal day is not defensible
from this sample," not as a null result. Two successive expected-uplift
simulations (delta x efficacy, then a horizon-dependent delta) were both
found to be mathematically incapable of producing a different cutoff
ranking regardless of the assumed effect size, because the assumed
parameters entered the formula as constants multiplying every (cutoff,
threshold) cell identically; this is reported as a designed-in
limitation of the uplift approach, not as a finding about intervention
effectiveness (`METHODOLOGY_NOTES.md`, entry 6).

## Combined takeaway

Across both studies, the structural-blindness construct (README §2.1)
holds to first order but not perfectly. In Study 1, H-S1.1c's null is
confirmed (size has no direct effect once spend is controlled) but
H-S1.2 shows that null is not perfectly homogeneous across ad-product
categories. In Study 2, H-S2.1's null is confirmed (account maturity
does not predict a new ad group's growth) and H-S2.2a/H-S2.2b show that
what *does* predict growth is the ad group's own early operating
signal, not inherited account history -- though neither H-S1.1c's nor
H-S2.1's/H-S2.2b's nulls reach formal TOST equivalence (README §7),
so both are reported as well-powered non-significant associations
rather than confirmed absences. The practical implication is the same
in both studies: account size or tenure should not be used as a proxy
for how a given advertiser or ad group will perform; what the unit
itself does -- spend, or its own first two weeks of activity -- is the
more informative, and more actionable, signal.
